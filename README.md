# React Fundamentals

This project demonstrates the core concepts of React.js through practical examples and mini projects.

## Topics Covered

- JSX
- Components
- Props
- State
- Event Handling
- Conditional Rendering
- Lists & Keys
- Forms
- React Hooks
  - useState
  - useEffect
  - useMemo
  - useCallback
  - useRef
- Custom Hooks
- Context API
- React Router
- Formik & Validation

## Tech Stack

- React
- JavaScript (ES6+)
- React Router
- Formik
- Bootstrap

## Purpose

The goal of this repository is to build a strong foundation in React and serve as a reference for future React and Next.js projects.
